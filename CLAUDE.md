# Project instructions

## Prompt logging

- Every user prompt must be appended to `docs/v1/prompts.md`.
- Do this at the start of handling each prompt, before any other work.
- Format: a `## <n>` heading (next sequential number), followed by the prompt verbatim in a fenced code block (use four backticks so prompts containing code fences are preserved).
- Never edit or remove earlier entries; only append.
