# Mortgage Calculator

A static web page that calculates an annuity mortgage. It is a personal and learning project, with the priority on correct math and clean, testable code.

## Features

- Monthly payment, total paid and total interest
- Full amortization schedule (up to 480 rows) in a scrollable table
- Chart of the remaining balance over time
- Chart of principal vs. interest per month
- Live results as you type, with no "Calculate" button
- Inline validation errors, and a warning for a down payment below 10 %
- Slovak number formatting (`1 234,56 €`), English UI

## Inputs

| Input | Range | Default |
|---|---|---|
| Property price | 10 000 – 2 000 000 € | 150 000 € |
| Down payment | 0 – 90 % | 20 % |
| Annual interest rate | 0 – 15 % (up to 2 decimals) | 4 % |
| Loan term | 1 – 40 years | 30 years |

The rate is nominal with monthly compounding (not an effective APR). The last installment is adjusted so the final balance is exactly 0.00.

## Getting started

Requires Node.js (development and tests only; the app itself has no build step and no backend).

```bash
npm install
npm start
```

Then open <http://localhost:4173>.

> Opening `index.html` directly from disk (`file://`) does not work, because browsers block ES modules there. Always use `npm start`.

Charts use Chart.js loaded from a CDN, so an internet connection is needed to see them.

## Scripts

| Command | What it does |
|---|---|
| `npm start` | Serve the app on port 4173 |
| `npm test` | Run unit and integration tests (Vitest) |
| `npm run test:e2e` | Run browser tests (Playwright) |
| `npm run golden` | Regenerate `tests/golden/golden.json` with the Python reference implementation |

## Project structure

```
index.html, styles.css   Page and styles
src/
  calc.js                Pure calculation logic (payment, schedule)
  validation.js          Input parsing and bounds checks
  format.js              Slovak-style number formatting
  config.js              Bounds and defaults
  outcome.js             Combines validation and calculation results
  main.js                Wires the form to the UI
  ui/                    form, summary, schedule and charts modules
tests/
  unit/                  Vitest tests for the pure modules
  integration/           UI tests with jsdom
  e2e/                   Playwright tests
  reference/reference.py Independent Python implementation
  golden/golden.json     Expected values generated by the reference
docs/v1/                 Specification, architecture, test scenarios, review, plan, retro
```

The calculation modules are pure and independent of the DOM, and they are checked against golden values produced by the Python reference.
